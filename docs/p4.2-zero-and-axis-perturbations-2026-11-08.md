# P4.2 零扰动与单轴小扰动验收

完成日期：2026-11-08

> 历史验收快照。本文的“下一步 P4.4”已完成；当前机械主线以仓库根目录 [CURRENT.md](../CURRENT.md) 为准。

## 这张卡做什么

P4.1 只定义了坐标系和三种感知假设。本卡不做 27 组全因子，也不改变送料动作、夹具或 PASS/FAIL 门槛，只回答一个更基础的问题：

> 对一根 Ø20 × 80 mm 棒料施加小的 `dy`、`dz` 或 world-Z `yaw` 后，静置、抓取和送料记录是否能复现？支撑结构会不会在抓取前把扰动消掉？

本轮命令入口使用 `--initial-yaw-deg`。旧的 `--initial-roll-deg` 仍可用，但只是兼容别名；它实际施加的也是绕世界 `+Z` 的 yaw，不是圆柱绕自身轴线的 roll。

## 实验固定项

| 项目 | 本轮值 |
|---|---:|
| 工件 | Ø20 × 80 mm，现有圆柱 |
| V 槽 | 90°，深 8 mm，长 24 mm，站位 −5 mm |
| 插入深度 | 25 mm |
| 托架 | 开启，内孔间隙 1.6 mm |
| `dx` | 0 mm，固定 |
| 位置扰动 | `dy = ±3 mm`、`dz = ±2 mm` |
| 姿态扰动 | world-Z `yaw = ±5°` |
| 静置 | 600 个仿真步 |
| 结果结构 | schema v7 |

每个 JSON 同时保存：

- `pose_before_perturbation`：施加扰动前的名义状态；
- `pose_after_perturbation_before_settle`：施加请求后的状态；
- `actual_initial_pose`：静置完成、机器人开始抓取前的真实状态；
- `grasp_target_pose`：本轮实际采用的抓取目标及其来源；
- `requested_initial_pose`：世界坐标偏移、world-Z yaw，以及旧参数兼容字段。

## 事实与解释边界

### 已证明

1. 新的 `yaw` 输入方向可验证：施加 `+5°` 后，静置前轴线为约 `(0.99619, +0.08716, 0)`；施加 `-5°` 后为约 `(0.99619, -0.08716, 0)`。
2. `dy ±3 mm`、`dz ±2 mm` 和 `yaw ±5°` 都能被记录到请求状态，且结果 JSON 保留了施加前、静置前和抓取目标。
3. 在当前 V 槽、台面接触、重力和下半环托架组合下，600 步静置后七个 case 的中心和轴线都回到了同一基准附近。
4. 这些 case 在现有项目判据下均完成并 PASS，没有引入作用在工件自由关节上的额外外力。

### 不能据此宣称

- 不能宣称机械臂在固定抓取目标下独立容忍了 `±3 mm / ±2 mm / ±5°`；
- 不能把本轮 PASS 当成视觉定位精度或 M0 固定目标抗扰成绩；
- 不能把静置后的真值抓取中心当成完整 M1，因为当前抓取姿态仍是固定标定姿态；
- 不能据此推出所有尺寸、插入深度或其他托架间隙都具有相同鲁棒性。

本轮更准确的结论是：**当前支撑结构会主动消除所选的小初始位置/偏航扰动，因此下一轮必须把“扰动被支撑消除”和“机器人对来料误差的处理能力”分开设计。**

```powershell
    --json-out _build\p42_yaw_plus5.json
```
