# 机械臂送料指标字典

更新：2026-11-08

## 用途与版本

本文是圆柱棒料送料任务的 v1 测量约定，不是行业标准。当前阈值用于项目内对照，后续可依据实验、工艺假设或可靠工程依据调整。

每条实验结果应区分两个版本：

- `metric_schema_version`：指标怎么算、单位是什么、在哪个阶段测。
- `criterion_set_id`：这次实验用哪一组 PASS/FAIL 门槛。

因此，改阈值不应改变指标公式，也不应覆盖历史结果。每次修改判据时，新增判据版本并记录修改原因；旧 case 保留原始测量值和原判定。若要按新门槛重新评估旧 case，应另存重评结果，并标明新 `criterion_set_id`。

目前可将本表门槛称为 `feed-criteria-v1`。下列门槛大多是**项目约定**；它们既不是生产安全保证，也不代表真实车床或机器人厂商的验收标准。

## 适用场景

主实验是 Ø20 × 80 mm 棒料、完整机械臂送料、V 槽抓取、无运动学搬运锁。卡盘单站测试、历史运动学锁路径、官方兼容场景应单独标注，不能混成一个通过率。

`verify_all.py` 的 10/10 表示仓库中列出的回归检查通过，不代表全部检查都是同一种真实物理送料模式，也不代表指标已由实机验证。

## 指标表

### 任务有效性与过程异常

这些指标回答“任务是否按预期完成”。硬失败不可由其他误差较小或平均值较好抵消。

| ID | 指标 | 定义 / 单位 | 测量阶段 | v1 判据 | 判据依据与状态 |
|---|---|---|---|---|---|
| V-01 | V 槽抓取接触数 | 棒料与 V 爪几何的接触记录数，个；不是独立接触面数量 | 抓取闭合完成、搬运开始前 | 全物理 V 槽路径必须 > 0 | 任务有效性门槛；零接触时应终止，不继续搬运或闭卡盘 |
| V-02 | 卡盘接触数 | 棒料与三爪 `jaw_geom` 的 MuJoCo 接触记录数，个 | 卡盘闭合并稳定后 | ≥ 6 | 项目约定；接触记录数不等于三爪均匀受力的证明 |
| V-03 | 20 N 轴向拉拔位移 | 沿世界 x 施加 20 N 后，棒料 x 位移绝对值，mm | 机器人退出、卡盘保持后 | ≤ 2.0 mm | 项目约定，仅覆盖当前载荷方向、大小和仿真时长 |
| V-04 | 棒料外加力峰值 | 交接期间施加到棒料自由关节平移自由度的最大外力分量，N | 抓取完成至交接结束 | 真实 V 槽交接路径要求为 0 N | 实验约束：不允许用外力替机械臂对中；重力、接触力、夹爪力不是此项外加力 |
| V-05 | 机器人-机床接触 | 按当前几何类别识别到的机器人与机床接触记录 | 全过程 | 目标为无非预期接触 | 当前代码分类仍需验证；接触对和几何归属核验完成前，不作成熟硬判据 |

### 姿态与装夹质量

这些指标回答“装夹结果是否达到本项目当前几何要求”。数值可以在新判据版本中调整。

| ID | 指标 | 定义 / 单位 | 测量阶段 | v1 判据 | 判据依据与状态 |
|---|---|---|---|---|---|
| Q-01 | 同轴误差 | 棒料中心相对卡盘轴线的径向距离：`sqrt(dy² + dz²)`，mm | 机器人退出、结果稳定后 | ≤ 2.0 mm | 项目约定；只看中心位置，不包含倾斜造成的端部偏心 |
| Q-02 | 轴线倾角 | 棒料轴线与世界 x（本模型的卡盘轴线）的夹角，度 | 机器人退出、结果稳定后 | ≤ 10° | 项目约定；不是棒料完整姿态误差，圆柱绕自身轴滚转不计入 |
| Q-03 | 交接 z 峰谷位移 | 从卡盘开始夹紧到松爪和退出期间，棒料中心 z 的最大值减最小值，mm | 整个交接过程 | ≤ 12 mm | 宽松甩料护栏，不是精度目标；当前代码注释称这是项目护栏 |
| Q-04 | 棒料余量偏心 | 棒料两端到卡盘轴线的径向距离中较大的一个，mm | 机器人退出、结果稳定后 | ≤ 2.0 mm | 基于当前 Ø20 粗车至 Ø16 的单边 2 mm 余量假设；工件/加工目标改变时必须重定 |
| Q-05 | 重力静置位移 | 机器人退出后静置期间棒料中心 z 的绝对变化，mm | 夹持完成后静置 | ≤ 2.0 mm | 项目约定；必须注明静置时长和支撑/外力状态 |

### 诊断量，不单独决定 PASS

| ID | 指标 | 定义 / 单位 | 用途与限制 |
|---|---|---|---|
| D-01 | 抓取姿态四元数角差 | 当前抓取姿态与初始姿态的整体旋转差，度 | 含绕圆柱自身轴滚转；不能替代 Q-02 轴线倾角 |
| D-02 | IK 位置残差 | 目标点与求解/实际末端位置之间的距离，mm | 大残差是诊断线索，不自动证明不可达；需结合关节限制和实际轨迹 |
| D-03 | 最小穿透深度 | 被跟踪接触对中的最小 contact distance，m | 负数表示几何重叠；当前采样范围和几何分类还需审计，不能单凭它宣称全过程无碰撞 |
| D-04 | 动作时间 | 本次仿真或动作阶段耗时，s | 用于效率比较；必须固定计时范围，并与成功率和质量指标一起报告 |
| D-05 | 三爪法向力 | 当前卡盘接触记录法向力之和，N | 用于观察接触状态；模型中的力值不是实机夹紧力标定 |

## 汇总判定规则

先分清三个问题，不要用一个“有效/无效”全包：

1. `trial_data_valid`：这次仿真是否留下可解释的尝试记录。正常完成或按预期抓空后中止，都算可用试验记录；NaN 等运行错误不算有效尝试结果。抓空没有后续卡盘质量指标，相关指标应为空，不能补零。
2. `evaluation_scope`：这条记录属于主全物理送料、带运动学锁的历史参考，还是其他诊断配置。只有声明的主实验配置进入主实验统计；其他配置可以报告，但不混入同一个成功率。
3. `outcome_class` 与原判据：可用的主实验尝试再分成功、硬失败、质量失败或中止。`hard_pass`、`quality_pass`、`overall_pass` 仍保留原含义，不能因新增标签而重算或覆盖。

P1.3 的机读字段写在 case JSON 顶层，`schema_version=3`；P2.1 加入复现配置字段升为 v4；P2.2 增加标准阶段检查点升为 v5；P2.3 加入全过程接触与外加载荷汇总，当前正式结果为 `schema_version=6`。P2.1-P2.3 只扩展记录结构，不改变指标算法或判据版本：

- `schema_version=6`：JSON 字段结构版本。
- `metric_schema_version=1`：指标定义版本。
- `criterion_set_id=feed-criteria-v1`：PASS/FAIL 门槛版本。

P2.1 还记录工件输入、初始位姿、控制模式、实际参数、已设置的相关环境变量、仿真选项、代码与依赖版本；P2.2 记录六个稳定节点；P2.3 记录逐物理步采样后的接触/外加载荷汇总和节点瞬时快照。20 N 拉拔测试在 `pull_test` scope 单独统计，不算送料期间的隐藏外力。详细验收见 [P2.1 实验 JSON 规范](p2.1-case-json-schema-2026-11-07.md)、[P2.2 六节点记录](p2.2-checkpoint-records-2026-11-08.md) 和 [P2.3 接触与外力记录](p2.3-contact-force-records-2026-11-08.md)。

| 字段 | 解释 |
|---|---|
| `evaluation_scope` | `primary_physics_feed`、`kinematic_lock_reference` 或 `diagnostic_configuration` |
| `trial_data_valid` | 完成或受控中止的仿真记录为 true；数值运行错误为 false |
| `include_in_primary_trial_stats` | 是否进入主物理送料统计；可用的 ABORT 也计入尝试次数和失败数 |
| `physical_task_success` | 只有主实验配置完整完成且原 `overall_pass` 为 true 才为 true |
| `outcome_class` | `physical_success`、`hard_fail`、`quality_fail`、`aborted`、`runtime_error`、`reference_pass/fail`、`diagnostic_pass/fail` 或 `missing_result` |

运行错误与子进程无 JSON 结果均单独报告，不算物理成功，也不静默当成物理失败。带锁对照即使 `overall_pass=true`，也只能标为 `reference_pass`，不得计入主实验成功率。

正式报告至少包含各指标原始值、`metric_schema_version`、`criterion_set_id`、控制模式、工件与夹具参数、代码版本、评价范围、数据有效性和结果类别。总体 PASS 不得隐藏失败阶段；批量统计报告成功分子/分母、失败类别、运行错误数量、分布和最差 case，不要只给平均值。

## 修改判据的记录模板

新增判据版本时记录：

| 字段 | 示例内容 |
|---|---|
| 新 `criterion_set_id` | `feed-criteria-v2` |
| 修改项 | `Q-01` 同轴误差上限 |
| 旧值 → 新值 | `2.0 mm → 待定` |
| 修改原因 | 工艺目标、敏感性实验或外部工程依据 |
| 影响范围 | 哪种尺寸、路径、工装和实验集适用 |
| 重评方式 | 是否重算历史 case；保留原始判定，不覆盖 |
| 批准状态 | 草案 / 项目采纳 / 有外部依据 |

没有数据或外部依据时，可以暂时调整以开展探索，但必须标为“草案”，不能宣称新阈值已经成为通用工程标准。
