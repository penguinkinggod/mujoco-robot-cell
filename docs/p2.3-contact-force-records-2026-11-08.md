# P2.3 全过程接触与外力记录

验收日期：2026-11-08

## 目标与边界

对完整送料仿真每个物理步采样一次接触和显式外加载荷，并按阶段汇总，能回答“哪两块几何在接触、接触法向力多大、仿真中显式施加了什么力”。六个 P2.2 检查点同时保存当下的接触与外加载荷快照。

本卡只增加观测和 JSON 字段，不修改机械臂动作、伺服、夹具、物理参数或 PASS/FAIL 判据。原有 `phase_stats`、穿透记录和外力硬判据保持原样。结果 JSON 从 `schema_version=5` 升为 `6`；`metric_schema_version=1`、`criterion_set_id=feed-criteria-v1` 不变。

## 记录内容

- `contact_diagnostics.scopes.feed`：送料、夹紧、松爪、退出、解锁静置各物理步的汇总，不含 20 N 拉拔测试。
- `contact_diagnostics.scopes.pull_test`：机器人退出后 20 N 拉拔阶段的独立接触汇总。
- 每个 scope 下有总体和分阶段汇总；按几何名称/机器人机身层级区分机器人-工件、机器人-机床、工件-机床、工件-支撑、机器人-支撑及其他接触。
- 每个接触对记录出现步数、每步峰值接触数、单个接触点法向力峰值、该对同一步法向力之和的峰值。
- `applied_load_diagnostics` 分别统计 `qfrc_applied` 的关节自由度分量和 `xfrc_applied` 的刚体力/力矩；检查点另存即时的非零外加载荷快照。
- 每个阶段快照的 `diagnostic_scope` 标明归属。拉拔测试里的 `shaft` 刚体力不会合并进送料 scope。

接触力峰值是 MuJoCo 接触点法向力的统计，不是实机夹紧力标定。类别峰值是该类别所有接触点法向力绝对值之和在某一物理步的最大值，不代表合力矢量。命名规则外的几何会进入 `other`，后续新增模型几何时应检查归属。
