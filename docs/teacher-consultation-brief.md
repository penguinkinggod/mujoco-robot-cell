# 大创 / 毕设方向咨询简报

更新：2026-11-10

## 我想做什么

我希望围绕小批量机加工上下料，研究机械臂把圆柱棒料送入三爪卡盘的过程。当前最关心的问题是：在明确的工件和来料范围内，夹具与送料参数会怎样影响抓取、卡盘交接和最终定位；能否通过有限参数搜索，找到比固定方案更可靠的配置。

暂定方向：**面向变尺寸棒料机床上下料的机器人仿真评测与参数优化**。这是工作方向，不是已经证明的研究创新。第一项研究需要进一步缩小到一个明确、可验证的问题。

## 目前基础

- 已有 MuJoCo 中的 SO-101、V 槽夹具、圆柱棒料和三爪卡盘送料仿真，可运行完整抓取、送料、夹紧、松爪和退出流程。
- 已做过 243 组受控仿真条件对比，并记录通过/失败和过程指标。
- 初步结果显示，支撑结构会影响棒料静置和自定心；因此这 243 组不能直接解释为机械臂对任意来料偏差的鲁棒性证明。
- 也做过一个无托架自由工件抓取诊断，但暂定抓稳指标没有全部通过。它还不是实际重力下的完整送料和卡盘交接验证。
- 2026-11-08 使用项目虚拟环境复跑无运动学锁送料：当前判据为 `FEED_METRIC PASS`，同轴误差 0.55 mm、倾斜 1.5°、卡盘交接位移 2.95 mm、余量偏心 1.42/2.0 mm。它们是当前仿真配置下的项目指标，不是行业标准，也尚不能作为稳定来料的正式基线。
- P5.8.7-P5.8.8 比较了固定 M2 估计误差下的送料前馈角，并补跑 nominal M1；六个指定条件上，全局 `2°` 与 M1=`1°`/M2=`2°` 候选均 PASS，但各质量指标有取舍，每条件只有单次筛查，不能说有统计优势。
- P5.8.9 对照了当前判据实现和历史记录：代码中的 `2.0 mm` 余量按 Ø20→Ø16 示例计算，仓库没有对应图纸或工艺卡确认；因此保留为项目暂定几何预算，不称实际加工规格或行业标准。
- 对照发现旧版在搬运期间会实时读取工件位姿修正路径；当前参数实验版本改为按抓取规划位姿搬运，以区分不同位姿信息条件。当前和旧版结果不能直接当作同一策略比较；细节见[版本对照报告](baseline-version-comparison-2026-11-08.md)。

## 当前限制与下一步

目前只有仿真，没有实体机械臂、实验室测量数据或已校准的真实设备模型。参数优化、大模型训练和真实加工验证都还没有完成。我本人也在学习 MuJoCo 和 Python；部分代码由 AI 工具协助实现，我正在补上对输入、运行过程和结果的理解，不会把尚未独立掌握的部分说成已完成。

P5.1 冻结了 Ø20 × 80 mm 棒料、两端静态 V 托架、真实重力、零扰动和 600 步等待。P5.2-P5.7 建立动作前稳定性、分阶段诊断、受控失败、固定基线重复性和接触/路径单因素对照；减速降低相对位移但使余量偏心超项目暂定门槛，接触设置影响较大但未标定。P5.8.2 修正闭爪斜坡未走满的问题；P5.8.3 对照带载末端跟踪；P5.8.4-P5.8.8 比较闭爪目标、抓取保持、送料前馈和指标取舍，但未证明对任意工况有唯一最优参数。P5.8.9 又逐项整理了 PASS/FAIL 判据，确认余量偏心的 `2.0 mm` 来自 Ø20→Ø16 示例而非实际规格文件。所有这些仍是 MuJoCo 仿真观察，无抓持容差、真实接触标定或真机结果。下一步 P5.8.10 先让有支撑来料的位置/姿态偏差能够保留到抓取开始，并验证抓取前实测位姿，避免把被托架自定心的样本误当成鲁棒性证据；SW→MC 共用数据仍后置。详细数值见 [P5.7 报告](p5.7-relative-motion-causes-2026-11-09.md)、[P5.8.6-P5.8.8 报告](p5.8.6-pickup-motion-and-feed-pitch-2026-11-10.md) 和 [P5.8.9 判据审计](p5.8.9-feed-criteria-audit-2026-11-10.md)。
