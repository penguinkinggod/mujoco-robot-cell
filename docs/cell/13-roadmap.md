# 未来

> README 里拆出来的，数字截至 2026-11-06。

这个仓库的第一用途是记录每天在学什么，第二用途才是作品。

四层目标，难度差着数量级。第一层站稳了，第二层基本成立，第三层刚开头：

| 层 | 内容 | 状态 |
|---|---|---|
| ① 跑通一个任务 | 仿真里把「抓起来 → 送进卡盘」做到接触可信 | 完成，9/9 |
| ② 别人能一键复现 | clone 下来 30 秒跑出结果，有判据有动图 | 基本成立 |
| ③ 参数化实验 | 爪型 / 直径 / 摩擦扫一遍，写成能引用的报告 | 直径已扫，绝对力待修摆位 |
| ④ 自训练策略、大模型设计爪型 | 通用性、泛化，实验室前沿 | 远期 |

顺序不能反。③ 之前仿真环境本身还不可信，在上面训出来的策略学的是「穿模也能过」的
物理，数据集整批作废。所以近期的取舍很清楚：先把仿真的可信度做实，再谈训练。

发布路线：代码留 GitHub，权重、数据集、在线 demo 走 Hugging Face（它的搜索按 model /
dataset 找，没人按代码找）。发布门槛不是「训练跑通了」，是泛化：换工件初始位姿仍能成。

## 这个 cell 里计划有四个工位

| 工位 | 状态 | 靠什么 | 目录 |
|---|---|---|---|
| 车床上下料 | 9/9 通过 | 手写 IK + 位置伺服 + V 槽/弧爪形封闭 | `src/scene_machining.py` |
| 视觉引导抓取 | 计划中（第 2 步） | 相机标定 + 位姿估计 | 计划 `scenes/vision_pick/` |
| 手势遥操作 | 计划 | 手部关键点 → 末端映射 | 计划 `teleop/` |
| 视频示教 / 模仿学习 | 计划 | BC / ACT 训练 | 计划 `learning/` |

这四个不是四选一，是一条数据链。视觉引导先解决「看得见」；手势遥操作解决「人怎么教」，
顺带录下 `(观测, 动作)` 序列；那批序列就是模仿学习的训练集。

## 底层是可以复用的

```
core/（计划）
├─ lock.py        把刚体钉在世界坐标，切断接触力传递
├─ handoff.py     两个执行器交接同一物体时的时序
├─ metrics.py     同轴度 / 接触数 / 拉拔位移 的量测
└─ camera.py      相机标定与图像采集

scene_machining   抓取 → 交接 → 夹紧 → 拉拔测试      （已完成）
scene_assembly    抓取 → 对齐 → 插入 → 紧固测试      （计划）
scene_vision      识别 → 定位 → 抓取 → 验证          （计划）
```

这次车床踩出来的「先松手、再退开、再夹紧」，装夹场景一模一样要用。场景会换，交接逻辑
不换。
