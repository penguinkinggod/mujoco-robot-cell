# 这个项目在学什么

这个仓库不是“做一个具身智能 demo”就结束，而是用一个具体工位持续学机器人仿真与操作。

## 选的任务

让 SO-101 从桌面抓起一根圆柱棒料，把它对准并送入车床三爪卡盘，再把工件交给卡盘。这个任务把几类问题放在一起：机械臂运动、夹持几何、接触与摩擦、相机定位、动作验证。

目前已经做出的是仿真里的物理送料和夹紧流程；还没有视觉引导、遥操作、模仿学习或真机验证。当前能复现的结果和运行方式以仓库首页为准。

## 为什么从 MuJoCo 开始

MuJoCo 轻、容易运行，适合先把碰撞、接触、控制和判据跑通。当前阶段的重点不是追求大规模训练，而是弄清楚：动作为什么成功或失败，指标是否真的测到了想测的事。

如果以后需要大规模并行训练，再评估换工具是否值得；现在不提前重造仿真平台。

## 项目做到什么程度算有价值

短期不是“训练出通用机器人”，而是把这个工位做成一个清楚、可复现的学习案例：

1. 能运行，知道模型、场景和控制脚本各自做什么。
2. 能用物理判据验证抓取、送料和夹紧，而不是只看动画像不像。
3. 能解释一次失败的来源，并用对照实验验证修正是否有效。
4. 接入视觉后，能把相机测得的位姿用于动作，并量出结果是否可靠。
5. 再讨论录制示教数据、模仿学习和泛化；每一步有用再做，不为路线图凑功能。

这是学习与工程验证项目，不是工业设备性能认证。仿真数字不能直接当成真机指标。

## 相关工作的边界

抓取仿真、SO-101 环境、车床上下料和软爪设计都有现成研究或开源实现。这里关注的是把这些东西放到一个可跑的具体工位中，学习如何建立有效判据、定位几何与控制问题，并记录可复现的结果。相关资料见[相关工作](research/related-work.md)。
