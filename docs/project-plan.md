# 项目计划

这不是必须全部完成的清单，而是用来判断下一步是否值得做。每一层先证明有用，再进入下一层。已经跨过的能力阶段和验证结果见[项目里程碑](milestones.md)，这里主要记眼下与后续方向。

## 当前阶段：建立可优化基准

先把任务、扰动、可调参数和验收指标固定下来。第一轮优化不追求复杂模型：用网格搜索、随机搜索或简单的贝叶斯优化比较候选参数，必须保留失败案例和未优化基线。

完成标准：同一批初始条件下，优化前后的成功率、同轴误差、倾斜、拉拔位移和动作代价可比较；每次结果能由脚本重跑，不靠手挑最好的一次。

## 后续阶段

### 1. 视觉引导

完成标准：改变工件初始位置或方向后，视觉结果能让机器人找到它，并通过明确的抓取判据。先做固定场景和少量扰动，不一开始就承诺泛化。

### 2. 遥操作与数据

完成标准：能从手势或其他输入控制末端，记录同步的观测、动作和结果；数据能回放，不先急着训练。

### 3. 模仿学习

完成标准：拿已有数据训练出可比较的策略，并和手写基线在同一组初始条件下比较成功率、失败类型和动作质量。

### 4. 泛化与真机

只有当前面结果稳定，才考虑更大范围的随机初始位姿、域随机化、sim-to-real 或换更强的仿真工具。

## 暂时不做

- 不为了“看起来像完整项目”提前创建 `core/`、`scenes/`、`teleop/`、`learning/` 空目录。
- 不把每次参数试探都扩成一张长期维护的表。
- 不把未来计划写成已完成成果。
- 不以训练跑通作为唯一成功标准。

新目录只有在代码真的出现第二个工位或第二类任务时再抽象；那时根据重复代码决定怎么拆。
