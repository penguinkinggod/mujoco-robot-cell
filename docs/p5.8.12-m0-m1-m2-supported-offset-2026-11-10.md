# P5.8.12：有支撑 `dy=-3 mm` 来料的 M0/M1/M2 对照

完成日期：2026-11-10

## 本轮问题

P5.8.11 在有支撑真实来料 `dy=+3 mm` 下比较了三种抓取目标来源。本轮只把物理来料偏移镜像为 `dy=-3 mm`，继续各运行一次 M0、M1、M2 完整物理送料，用同一协议检查偏移方向是否会改变抓取过程。

- **M0 固定目标：** 目标仍是名义工件中心 `(260, -130, 39.812) mm`，不读取当前偏移。
- **M1 真值重定位：** 使用静置后的 MuJoCo 工件位姿；这是理想仿真真值，不是视觉定位。
- **M2 带误差估计：** 使用仿真真值加冻结的合成误差，不是相机测量。

## 固定条件

| 项目 | 本轮设定 |
|---|---|
| 工件 | 钢圆柱 Ø20 × 80 mm，质量约 0.1973 kg |
| 工装 | 90° V 爪、两端 V 托架；支撑与工件一起平移 |
| 抓取前物理位姿 | `dy=-3 mm`、`dz=0 mm`、world-Z yaw `0°`；真实重力静置 600 步 |
| 送料 | `--lift --no-lock`，完整物理送料，名义插入 25 mm |
| 规划模式 | M0、M1、M2 各一例 |
| M2 合成误差 | `dy=+0.203443 mm`、`dz=+0.312274 mm`、yaw `+1.051870°` |
| 随机种子 | 三例均为 `0`；M2 沿用 P5.8.11 的同一误差向量，以隔离物理偏移方向；它不是 P4.3 负偏移样本对应的另一条冻结误差 |
| 代码版本 | `b77a6e0f4696a0c57b6237219a03ffb76d64ea84`；JSON 记录工作树干净 |

静置后的真实工件中心为 `(260, -133, 39.812) mm`。M0 仍瞄准名义位置，与实际中心相差 `+3.000 mm`。M1 使用真实中心。M2 的估计中心约为 `(260, -132.797, 40.124) mm`，相对真实中心的位置估计误差约 `0.373 mm`，并带 `+1.052°` yaw 误差。M2 的误差是世界坐标中的同一误差输入，不随物理偏移符号反转。

在这两个固定样本中，M1/M2 的抓取过程指标相近；M0 的正向样本比负向样本出现更多下降阶段接触，并有更大的夹紧阶段轴线变化和完整姿态差。这个差异说明当前模型和路径存在方向敏感性，值得继续针对 M0 正向情况调查；它不证明一般性的偏移规律，也不代表 M0 必然更差。`grasp_tilt_deg` 是工件完整四元数相对 nominal 的旋转差，包含圆柱自身轴向转角，不等于轴线倾角。

两个方向的三种模式都通过当前送料判据，仍不能据此说抓取过程等价。`stock_ecc_mm` 在 M2 负向样本为 `1.830 mm`，距离项目暂定 `2.0 mm` 门槛较近；该门槛尚未由图纸或工艺卡确认。过程位移、姿态变化也没有独立工程合格线，因此不排名“最佳模式”。

## 证据边界

- 每个方向和模式都只有一个单例；六个 PASS 不是成功率、重复性、置信区间或任意姿态鲁棒性。
- 本轮只测 `dy=-3 mm`，并与上一轮 `dy=+3 mm` 配对；没有测试其他偏移量、高度、yaw 或工件尺寸。
- M1 读取 MuJoCo 真值；M2 是固定的合成误差输入，两者都不是视觉系统精度证据。
- `FEED_METRIC PASS` 仅说明满足当前项目判据；余量限值 `2.0 mm` 是暂定几何预算。
- 接触和位姿变化来自未经实物标定的 MuJoCo 模型；抓取阶段诊断没有独立合格门槛。
- 本轮未修改路径、夹爪、控制器、接触模型、阈值或代码默认值。
