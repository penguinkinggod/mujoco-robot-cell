完成日期：2026-11-08

> 历史设计快照。本文的“下一步 P4.4”已完成；当前机械主线以 [CURRENT.md](../CURRENT.md) 中的 P5.6 为准。

## 这张卡冻结什么

冻结 P4.4 受控网格实验的工件来料扰动、三种感知/抓取目标模式、插入深度、M2 合成估计误差，以及 P4.5 调参/留出集使用的 seed。

这张卡**只定义清单和生成规则**，没有运行 27 个样本乘深度/模式组合的仿真，也没有改送料动作、工装或 PASS/FAIL 判据。

机器可读清单：

- [p4.3-shared-samples-v1.json](p4.3-shared-samples-v1.json)
- 生成和校验脚本：[diag_feed_perturbation_manifest.py](../src/diag_feed_perturbation_manifest.py)

## 统一的样本含义

基础来料扰动沿用 P4.2 的入口时点：

1. `mj_resetData` 后给工件施加 `dx/dy/dz/yaw` 请求值。
2. 工件按当前 V 槽、台面、重力和托架静置 600 步。
3. 静置结束、机器人开始接近前，读取真实位姿，作为 `true_pose_before_grasp`。
4. M0/M1/M2 共享同一个来料请求和静置过程；用于规划的位姿信息按模式隔离。

因此这份清单研究的是**来料初始摆放 + 当前支撑结构的自定心 + 机器人抓取**。P4.2 已显示支撑可能把请求偏差消掉；不得把请求值直接当作抓取时仍存在的实际误差。结果必须同时保留请求值与静置后真值。

## 冻结的 27 个基础来料样本

采用完整三因子网格：

| 因子 | 固定/取值 |
|---|---|
| 轴向偏移 `dx` | 固定 `0 mm` |
| 横向偏移 `dy` | `−3, 0, +3 mm` |
| 高度偏移 `dz` | `−2, 0, +2 mm` |
| 绕世界 `+Z` 的 `yaw` | `−5, 0, +5°` |
| 组合数量 | `3 × 3 × 3 = 27`，零扰动只出现一次 |
| 排序 | `dy`、再 `dz`、再 `yaw`，各自从小到大 |

每个样本 ID 固定写入 JSON，例如 `p43_dy_m3_dz_z0_yaw_p5`。完整 27 行位姿数值及其稳定 ID 以 JSON 文件为准，后续运行不得临时重抽、删掉失败样本或改 ID。

网格本身是笛卡尔积、并不依赖随机数；清单明确记录这一点，不能用一个虚构的 seed 改变行顺序或重抽网格点。M2 网格误差使用单独 seed，train/holdout 也各用独立 seed。

## M0 / M1 / M2 对照定义

三种模式必须使用完全相同的物理来料样本、静置步数、插入深度和判据：

| 模式 | 规划可读取的数据 | 抓取目标规则 | 解释 |
|---|---|---|---|
| M0 固定目标 | 固定标定目标；规划不能使用本 case 的测量位姿 | 所有 case 使用名义目标 | 测固定目标对整个来料/支撑变化的表现 |
| M1 真值 oracle | 静置后的仿真真实位姿 | 用真值重算位置与轴线姿态 | 理想感知上限，不代表真实视觉 |
| M2 带误差估计 | M2 估计位姿；规划不可直接读取真值 | `estimated_pose = true_pose + error`，据估计值重算抓取目标 | 测合成定位误差下的敏感度 |

M0/M1/M2 只改变目标规划可用的信息，不得改变工件真实状态、接触物理、夹具、送料动作或判据。记录器可以保存真值以供事后分析，但 M0/M2 的规划接口不得直接消费真值。

## M2 误差是假设，不是相机指标

目前没有实体相机或标定数据，所以冻结一个**探索性仿真误差包络**，只用于比较算法对误差的敏感度：

- 估计横向误差 `error_dy`：均匀分布 `[-1, +1] mm`；
- 估计高度误差 `error_dz`：均匀分布 `[-1, +1] mm`；
- 估计偏航误差 `error_yaw`：均匀分布 `[-2, +2]°`。

27 个网格样本各自的 M2 误差三元组已经由 `m2_grid_error_seed=20261109` 生成并固化在 JSON 中。后续不同插入深度必须复用该样本对应的同一个误差值，不得每档重新抽噪声。

这些误差范围没有现实传感器证据支持。项目报告必须称其为“仿真假设/敏感度测试”，不能写成视觉系统精度或实际设备规格。

## 插入深度和正式矩阵数量

每个来料样本都要在插入深度 `8 / 10 / 25 mm` 和模式 `M0 / M1 / M2` 下配对：

`27 个物理样本 × 3 个插入深度 × 3 种模式 = 243 次正式仿真`

原计划中的 `81` 只计算了 `27 × 3 个深度`，漏算了三种模式。现在更正为总数 243；每个深度、每种模式各有 27 次。零偏差基准是 27 个样本中的一个，不再额外重复计数。

唯一通过条件仍使用 `feed-criteria-v1`。M0/M1/M2 及 8/10/25 mm 的失败、ABORT、ERROR 都要保留，不能只统计成功组。

## P4.5 随机调参与留出样本

冻结未来生成规则，但本卡不生成/运行这 40 个随机样本：

| Split | 数量 | 固定 seed | 用途 |
|---|---:|---:|---|
| `train` | 20 | `20261110` | 可用于后续选参数 |
| `holdout` | 20 | `20261111` | 只用于最终验收，不能调参 |

工件请求值在 P4.3 已冻结的来料范围内独立均匀采样；M2 误差在上述 M2 包络内独立均匀采样。P4.5 必须把实际生成的 40 条完整数值写入独立版本化清单，再开始使用；seed 不能替代保存实际样本。

## 验收边界与下一步

- 清单包含 27 个不重复的完整网格点，零点恰好一次。
- M2 的误差值由固定 seed 生成，27 行误差都在声明范围内，并已固定在清单中。
- M0/M1/M2 使用同一真实来料样本；完整矩阵数为 243。
- P4.5 的 train/holdout seed 已预先固定，holdout 明确不可用于调参。
- 本卡没有运行 243 组仿真，也没有证明任何扰动成功率。
