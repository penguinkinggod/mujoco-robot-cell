# P5.2 动作前稳定性与记录修正

完成日期：2026-11-09

## 本卡结论

冻结的 P5.1 nominal 在机器人动作前的最后 100 个仿真步内通过了本项目的来料稳定性检查；全物理送料也按现有 `feed-criteria-v1` 判据得到 `FEED_METRIC PASS`。结果 JSON 的 `nominal_start_position_m` 已改为从送料模型 reset 后、施加请求扰动前的实际工件位置读取，不再引用 `scene_machining`。

这证明的是**当前单一仿真工况**下的等待状态和送料结果，不是多次重复统计、其他工件/姿态的保证，也不是实机验证。

## 检查设置与判据

固定工况：Ø20 × 80 mm、约 0.1973 kg 钢制圆柱棒料；零位置/偏航扰动；真实重力 `[0, 0, -9.81] m/s²`；两端静态 V 托架；等待 600 步，`dt=0.002 s`；M1 仿真真值规划；无运动学锁搬运。

等待末段采样窗口为最后 100 步：100 个连续样本，采样间隔 0.002 s，首末样本时刻跨度 0.198 s。逐样本记录中心位置、圆柱轴线、线/角速度、左右托架接触数，以及施加到工件自由关节和刚体上的外加力/力矩。窗口不足 100 步时状态为 `insufficient_samples`，不判 PASS。

本项目的稳定性 PASS 同时要求：

- 整根棒料端点相对窗口首样本的最大位移不超过 0.20 mm。端点位移同时包含中心平移和轴线转动。
- 左、右托架在 100/100 个样本中都与工件保持接触。
- 重力为 `[0, 0, -9.81] m/s²`，工件 `gravcomp=0`。
- 工件自由关节与刚体上没有施加外力或外力矩。

`0.20 mm` 是当前项目的**暂定预算**，按现有 2.0 mm 单边加工余量的 10% 设定；它不是行业标准，也不是独立测得的夹爪捕获公差或 MuJoCo 通用数值精度。速度会记录，但本卡没有另造速度阈值。

同次完整送料结果：

- `FEED_METRIC PASS`；同轴误差 `0.55 mm`、轴线倾角 `1.5°`、卡盘接触记录 `30`、交接 z 峰谷 `2.95 mm`、余量偏心 `1.42 mm`。

- JSON 另外记录最小接触距离 `-0.002991 m`，接触对为 `shaft_geom|moving_jaw_pad_v2`，阶段为搬运。这相当于约 `2.99 mm` 的几何重叠。现有送料 PASS 判据不检查该量，因此**不能据此宣称整个接触模型无穿透**。P5.3 开始阶段分层验收前，应先核查该接触对和重叠量是预期 V 槽接触、接触求解现象还是几何/路径问题；本卡没有改抓取路径、夹具或阈值。

## 边界与下一步

本卡没有测重复运行方差、其他等待时长、不同工件或其他来料姿态；也没有测真实传感器误差、加工力学或真机表现。`0.20 mm` 只用于项目内固定 nominal 稳定性检查，后续若要把它作为正式研究门槛，需要进一步做重复试验、接触参数敏感性和夹爪捕获余量分析。

下一卡为 P5.3：先核查本报告发现的搬运期棒料/V 爪几何重叠，再把接近推料、夹持保持、搬运滑移和卡盘接管分阶段记录/判定；至少保留一个 nominal 通过案例和一个受控失败案例。不扩姿态大扫描、不训练模型。
