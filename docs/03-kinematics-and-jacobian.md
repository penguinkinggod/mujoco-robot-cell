# 03 · 运动学与雅可比：关节转到几度，末端才到那个点

## 两个方向的问题

| 方向 | 问题 | 难度 |
|---|---|---|
| **正运动学 (FK)** | 我告诉你 7 个关节各转多少度，末端在哪？ | 简单，乘一串矩阵就行 |
| **逆运动学 (IK)** | 我要末端到那个点，7 个关节该各转多少度？ | 难，没有唯一解，有时无解 |

`demo_02` 用的是 IK，但**不是靠公式推的**，是靠迭代逼近。这对零基础更友好。

## 迭代 IK 的五步循环

```
重复 400 次：
  1. 当前末端在哪？           -> 正运动学，mj_forward 帮你算
  2. 离目标差多少？           -> err = goal - ee
  3. 每个关节动一点，末端往哪走？  -> 雅可比矩阵 J
  4. 反推：末端要走 err，关节该走多少？ -> dq = pinv(J) @ err
  5. 走一小步（限幅），回第 1 步
```

## 雅可比矩阵，用人话讲

J 是一张"换算表"：

> 关节 1 转 0.01 弧度 → 末端在 x 方向动 0.003 m、y 方向动 0.0005 m……

它有 3 行（x/y/z 三个方向）、2 列（两个关节）。`demo_02` 里就是这两行：

```python
jacp = np.zeros((3, model.nv))
mujoco.mj_jacSite(model, data, jacp, None, SITE_ID)
J = jacp[:, :2]        # 只取两个转动关节对应的两列
```

**你不需要推导它，MuJoCo 帮你算。但你必须知道它是什么**，因为：

- 正向用 J 是"关节速度 → 末端速度"
- 反向用 J 的伪逆是"末端速度 → 关节速度"（这就是 IK 的核心）

## 为什么要"限幅"和"阻尼"

`demo_02` 这两行：

```python
if n > STEP_GAIN:
    dq = dq / n * STEP_GAIN
```

不限幅的话，J 在"奇异位形"（比如手臂完全伸直）附近会爆掉，关节瞬间跳到几百度。
真实机械臂会直接报警停机。**限幅不是胆小，是工程。**

`demo_04` 里还多了一个 `lam`（阻尼系数），原理一样：让求解稳一点，宁可慢一点也不要跳。

## `demo_04` 比 `demo_02` 多了什么

| | demo_02 | demo_04 |
|---|---|---|
| 关节数 | 2 | 7（冗余，更容易有多解） |
| 约束 | 只管位置 | 位置 + **姿态**（6 维） |
| 求解方式 | `pinv` | 阻尼最小二乘 `J.T @ solve(J@J.T + λ²I, err)` |
| 执行方式 | 直接改 `qpos` | 只给 `ctrl`，交给伺服 |

**加姿态约束是必须的**：只解位置，夹爪会歪着过去，夹不住方块。
我第一次跑就是这么失败的（末端到了，但方块没夹住）。

## 你可以试的

`demo_02_arm.py` 里把 `STEP_GAIN = 0.01` 改成 `0.1`，重跑。
看末端轨迹是更平滑了，还是开始抖动/画圈。

**这就是"步长 vs 稳定性"的权衡**，优化、控制、数值方法里到处都是这个矛盾。
