# P5.3 分阶段记录与受控失败验收

日期：2026-11-09

## 结论

P5.3 已完成本轮约定的分阶段观测与负向验收。代码现在能分别回答：

- 机械臂接近工件时，工件最多被推移多少；
- 抓取闭合后、送料到卡盘前，工件相对夹爪最多平移多少、轴线相对变化多少；
- 抓空时是否明确中止，并阻止后续搬运和卡盘闭合。

新位移量是**诊断量**，没有被加进 `FEED_METRIC` 的 PASS/FAIL，也没有新造一个未经验证的“允许滑移毫米数”。名义样例的端到端送料仍为 PASS，但搬运期间观测到 `8.152 mm` 最大相对平移；这揭示了当前端点 PASS 没覆盖过程滑移，不能把它说成“搬运抓得稳”。

## 阶段判读

| 阶段 | 记录量和依据 | 当前怎么判 |
|---|---|---|
| 来料静置 | `initial_stability`：最后 100 步、左右托架接触、端点位移、重力及工件外加力 | 项目暂定稳定性检查；窗口缺失或失败不能算合格主扫描输入 |
| 接近、侧向进入、下降、夹紧 | `pickup_motion_diagnostics`：以静置后的抓取前位姿为参照，记录工件中心最大位移、轴线变化、机器人-工件接触步数和法向力峰值 | 记录推料现象，不单独判 PASS/FAIL；当前接近阶段移动没有独立工程容差 |
| 抓取结果 | `metrics.grasp_contact_count` | 全物理 V 爪接触数必须大于 0；为 0 时 `FEED_ABORT`，后续送料和卡盘动作取消 |
| 搬运和轴向进给 | `gripper_relative_workpiece_motion`：从抓取保持完成时开始，以夹爪坐标系比较棒料中心相对夹爪中心的平移变化和棒料轴线变化，逐步统计并分开汇总搬运/进给 | 新增诊断量，没有独立滑移门槛；不能把最终卡盘质量通过当成搬运过程无滑移 |
| 卡盘接管和夹爪退出 | 六个 `checkpoints`、最终同轴/倾角/卡盘接触/拉拔、静置滑移、交接峰谷和棒料余量偏心 | 继续采用 `feed-criteria-v1` 的既有硬失败与质量判据；项目门槛不是行业标准 |

相对位移以夹爪坐标系描述，因此机械臂整体移动不会被误算成工件滑移。轴线变化能发现工件相对倾斜，但不测圆柱绕自身长轴的滚转。当前门槛只检查是否接触，不等于已证明 V 槽有足够承载裕量。

## 名义结果

条件：Ø20 × 80 mm 工件、静态双 V 托架、真实重力、600 步静置、M1 真值规划、无运动学锁、名义零扰动。

| 指标 | 结果 |
|---|---:|
| 动作前稳定性 | PASS；左右托架各 100/100 步接触 |
| 接近至夹紧期间中心最大位移 | `0.443 mm` |
| 接近至夹紧期间轴线最大变化 | `0.578°` |
| 搬运期间相对夹爪最大平移 | `8.152 mm`，仿真时间 `7.912 s` |
| 搬运期间相对轴线最大变化 | `1.528°` |
| 轴向进给期间相对夹爪最大平移 | `6.379 mm` |
| 卡盘接管后的现有端点结果 | 同轴 `0.547 mm`、倾角 `1.464°`、卡盘接触 `30`、20 N 拉拔 `0.00148 mm` |
| 交接与加工余量结果 | 交接 z 峰谷 `2.948 mm` / 项目护栏 `12 mm`；余量偏心 `1.420 mm` / 项目限值 `2.0 mm` |
| 原判据汇总 | `FEED_METRIC PASS`；没有硬失败或质量失败 |

因此，本结果证明的是“这个固定仿真案例按现有端点判据完成了交接”。它同时发现约 8 mm 的搬运相对位移，下一阶段必须先复核该量的运动学定义和重复性，再决定是否能为它设合理门槛。不能把 8.152 mm 直接宣布为可接受，也不能据单次结果判为抓取失败。

## 受控失败结果

本轮用两个负向样例覆盖两种不同结果类别：

**抓空中止。** 工件保持名义位置和稳定托架，仅在 M2 规划输入中加入 `dy=+30 mm` 的人工位姿估计误差。该数值是用于触发保护逻辑的测试输入，不代表传感器精度或真实误差分布。

- 动作前稳定性：PASS；左右托架各 100/100 步接触。
- 闭爪后 V 爪接触：0。
- 终止标签：`execution_status=aborted`、`abort_stage=grasp`、`abort_reason=no_v_jaw_contact`、`hard_failures=["grasp_empty"]`。
- 终止行为：进程退出码 `1`；记录中没有 `feed_complete`、没有卡盘检查点，卡盘接触、拉拔、静置滑移等后续指标保持空值。
- 结果分类：`outcome_class=aborted`；不是成功，也不是运行时错误。

这证明“这个稳定输入下的人工定位错误会导致抓空，而且程序会停止而不是继续伪报成功”。它不说明 `30 mm` 是现实相机误差，也不验证其它抓取失败类型。

**完整执行后的质量失败。** 使用已知探索工况 `FEED_V_CONTACT_SOLREF_TIME=0.005`，工件输入和动作仍保持 nominal。该档此前的复跑已知会使余量偏心超过现行项目限值；此处用于检查完整流程失败分类，不表示推荐该接触参数。

- 动作前稳定性：PASS；完整流程运行结束，六个卡盘交接检查点均完成。
- `execution_status=completed`，`hard_pass=true`，`quality_pass=false`，`overall_pass=false`。
- 唯一质量失败原因：`quality_failures=["stock_eccentricity"]`；实测 `2.100677 mm`，限值 `2.0 mm`。
- 结果分类：`outcome_class=quality_fail`；进程退出码 `1`，但不是 ABORT，也不是运行时错误。

这证明完整仿真里“硬任务执行完了”和“几何质量没达到当前项目门槛”会被分开记录；其它指标不能抵消这个余量偏心失败。

## 复现

名义通过案例：

```powershell
.venv\Scripts\python.exe -X utf8 src\diag_feed_chuck.py `
  --v-jaw --lift --no-lock `
  --initial-dy-mm 0 --initial-dz-mm 0 --initial-yaw-deg 0 `
  --initial-settle-steps 600 --control-mode M1 `
  --case-id p53-phase-nominal-2026-11-09 `
  --json-out _build\p5.3-phase-nominal-2026-11-09.json
```

稳定来料上的受控抓空：

```powershell
.venv\Scripts\python.exe -X utf8 src\diag_feed_chuck.py `
  --v-jaw --lift --no-lock `
  --initial-dy-mm 0 --initial-dz-mm 0 --initial-yaw-deg 0 `
  --initial-settle-steps 600 --control-mode M2 `
  --m2-error-dy-mm 30 `
  --case-id p53-phase-wrong-pose-2026-11-09 `
  --json-out _build\p5.3-phase-wrong-pose-2026-11-09.json
```

完整流程的受控质量失败：

```powershell
$env:FEED_V_CONTACT_SOLREF_TIME = "0.005"
.venv\Scripts\python.exe -X utf8 src\diag_feed_chuck.py `
  --v-jaw --lift --no-lock `
  --initial-dy-mm 0 --initial-dz-mm 0 --initial-yaw-deg 0 `
  --initial-settle-steps 600 --control-mode M1 `
  --case-id p53-quality-fail-solref005-2026-11-09 `
  --json-out _build\p5.3-quality-fail-solref005-2026-11-09.json
$LASTEXITCODE
Remove-Item Env:FEED_V_CONTACT_SOLREF_TIME
```

抓空命令预期以退出码 `1` 结束并打印 `FEED_ABORT`；完整质量失败则打印 `FEED_METRIC FAIL`，JSON 区分 `quality_fail`。三个 JSON 存放在被 Git 忽略的 `_build` 目录；本报告保存关键结果和复现条件。

## 版本、测试与边界

结果 JSON 从 schema v11 升为 v12，以容纳 `pickup_motion_diagnostics` 和 `gripper_relative_workpiece_motion`。`metric_schema_version=1` 与 `criterion_set_id=feed-criteria-v1` 不变，因为新记录没有改判据。扫描器与敏感性脚本已更新为读取 schema v12；旧的 v11 结果仍是当时有效的历史记录，不能冒充包含新诊断的 v12。

本卡没有调 V 槽、改变抓取路径、接触参数、仿真门槛或训练模型。接触重叠仍需物理标定；搬运相对位移还需要重复性和局部坐标实现的独立复核。全部回归通过后再把本卡标为完成。
