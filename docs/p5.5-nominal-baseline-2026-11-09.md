# P5.5 固定 nominal 基线与相对夹爪位移复核

完成日期：2026-11-09

## 本卡回答的问题

先前单次 nominal 记录到抓取后搬运相对夹爪最大平移约 `8.152 mm`。本卡检查两件事：这是不是只因为机械臂整体移动/转动造成的坐标假象，以及固定仿真条件下能否重复得到同一结果。

结论：夹爪坐标变换通过了旋转不变性单测，固定版本上的三次独立完整送料均得到相同数值。约 `8.152 mm` 是本仿真模型里可重复观察到的工件中心相对夹爪中心的位置变化，不是随机噪声；但尚无独立验收阈值，也没有实物接触标定，不能据此判断为工程上可接受或不可接受，更不能声称“已经抓稳”。

## 测量定义核查

当前 `Arm.pad_center()` 在 V 爪模式下返回两处夹爪参考几何中心的平均位置，`gripperframe` site 提供夹爪坐标系的旋转矩阵 \(R\)。每个时刻计算：

```text
r_tool(t) = R(t)^T [p_shaft(t) - p_pad_center(t)]
delta_r_tool(t) = r_tool(t) - r_tool(t0)
translation_mm(t) = 1000 * ||delta_r_tool(t)||
```

其中 `t0` 是抓取保持稳定后的搬运起点。因为工件中心与夹爪中心都在每一时刻转换到同一当前夹爪坐标系，机械臂整体平移或整体转动本身不会被算成相对滑移。工件轴线也转换到夹爪坐标系，轴线角差采用 `abs(dot)`，因此圆柱绕自身轴线的滚转不在这个轴线指标中体现。

代码现已将坐标运算提取为 `_pose_in_tool_frame()` 和 `_relative_pose_change()`，并增加两项单元测试：

- 工具整体旋转 `73°`，工件相对工具刚性不变：计算平移变化为 `0`、轴线变化为 `0°`（数值容差内）。
- 工具旋转并整体移动，同时人为增加工具局部 `4 mm` 位移：计算结果为工具坐标中的 `4 mm`。

这验证了定义与实现的数学一致性；它不验证 MuJoCo 接触参数、材料、摩擦或真实夹持力。
