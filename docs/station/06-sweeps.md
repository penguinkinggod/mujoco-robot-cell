## 把接触面改小

`src/diag_jaw_face_sweep.py` 扫半包角 36~52°、段间重叠 1.00 / 1.02、弧片厚度 2.5 / 5 mm。
结论是包角缩到 45° 以下互顶就归零，临界很陡：45° 还是 0，46° 突然 845 N。

代价一开始看着几乎没有：包角 104° → 88°，接触点仍是 30，三爪力 168 → 164 N，同轴
0.15 → 0.21 mm。**但第一版选的 42° 把主线体检打挂了**，三爪力比从 1.6 涨到 4.24。
短弧片把三爪 0.1 mm 的同步差放大，某一爪先吃到力。力比随包角不是单调的，得单量：

| 半包角 | Φ15 互顶 | 主线三爪力比 | 结果 |
|---|---|---|---|
| 52°（原值） | 1274 N | 1.27 | 互顶挂 |
| 42° | 0 | 4.24 | 力比挂 |
| **44°（现在）** | **0** | **1.15** | **两头都过** |
| 46° | 845 N | — | 互顶挂 |

44° 在四种厚度 / 重叠组合下力比全在 1.07~1.69，离 46° 临界还有 2° 余量，取它。出厂只
改了 `JAW_ARC_HALF_DEG` 一个数字（52 → 44），每爪 88°、三爪 264°、缝 3×32°，反而更
接近真机软爪，本来就不该包满。

改完用 44° 重跑全直径（`--full`，旧摆位 / 已作废）：

| 组 | Φ15 | Φ18 | Φ20 | Φ22 | Φ25 |
|---|---|---|---|---|---|
| 按径定制爪 | PASS | PASS | PASS | PASS | PASS |
| 固定 Φ20 爪 | **FAIL** | PASS | PASS | PASS | PASS |

新摆位下这张表变成：按径定制爪 Φ15 也 FAIL（互顶 42 对），固定 Φ20 爪 Φ15 FAIL
（48 对），其余八组 PASS。

（以下两段是旧摆位当时的结论，现已证伪，留作过程记录。）

换爪这条路 Φ15~Φ25 全通，同轴 0.11~0.21 mm、倾斜 0.40~0.49°、拉拔全 0.00 mm、背板
互顶全 0。不换爪只剩 Φ15 不行：固定 Φ20 弧面和 Φ15 料之间有 2.7 mm 间隙，三爪得多往里
走一截才够得着，那一截又把端点送进彼此的缝里（1600 N）。当时判成「行程问题，不是包角问题」。

这几条随旧摆位一起作废：`chuck_body_N` 不再是 1~4 kN（新摆位十组全 0），三爪力可以引用；
Φ15 的失效是 44° 包角在细料上角向缝不够，42° 以下就能过，是包角问题不是行程问题。
爪间互顶仍只数 > 1 N 的接触。

## 新摆位下的包角重扫（阶段 8，2026-11-06 夜）

卡盘开了 Φ30 通孔、扫描摆位换成主线工况之后，把旧表里的互顶列重扫了一遍。
`W.run_case(D, 'fit', half_deg=h)`，`INSET=0.055`，判据同上。力比那一列不用重扫，
它来自 `diag_chuck_health` 的主线场景，与扫描摆位无关。

| 半包角 | Φ15 互顶 | Φ20 互顶 | Φ15 爪力 | Φ20 爪力 | Φ20 同轴 | Φ20 判定 |
|---|---|---|---|---|---|---|

| 40° | 0 | 0 | 161 N | 150 N | 0.291 mm | 过 |
| 42° | 0 | 0 | 163 N | 145 N | 0.250 mm | 过 |
| **44°（现在）** | **42 对 / 971 N** | **0** | 536 N | 141 N | 0.230 mm | 过 |
| 45° | 48 对 / 1161 N | 0 | 576 N | 140 N | 0.193 mm | 过 |
| 46° | 48 对 / 1233 N | 0 | 593 N | 140 N | 0.184 mm | 过 |
| 48° | 42 对 / 1203 N | 0 | 581 N | 141 N | 0.207 mm | 过 |
| 52° | 42 对 / 1491 N | 3.6 N 擦边 | 573 N | 184 N | 0.211 mm | 过 |

十六组 `chuck_body_N` 全 0。两处结论变了：

- 旧表那条「45° 还是 0、46° 突然 845 N」的陡峭临界，在新摆位下**不复现**。Φ20 从 36°
  到 52° 全程不互顶，只有 52° 有 3.6 N 擦边。那个临界是实心卡盘加旧摆位的产物。
- Φ15 的临界前移了：旧表 44° 还是 0，新摆位下 44° 就冒出 42 对互顶，**42° 是最后安全点**。
  这和 README 正文「44° 是按 Φ20 定的，细料角向缝不够」一致，只是更精确。

主线不用改。44° 现在的依据不是「离互顶临界还有 2° 余量」，而是力比那一列：36 / 40 / 42°
分别 6.64 / 2.62 / 4.24，44° 是 1.15，45° 在减薄组合下会挂 3.25（§27）。
这个数由主线体检的鲁棒性定，不由互顶定。参数化到此封线。
