# 目前的局限

> 车床工位技术记录；当前状态以仓库首页为准。

1. **接触段还有 2~4 次起步。** 搬运段已经是一条连续曲线（1 次起步、静止 0.01 s），
   剩下夹紧、进给、松爪这几处是接触力把末端推偏、闭环再补一小步，前馈解决不了，
   要动的是接触模型而不是曲线。
2. **默认路径的搬运段仍用 `kinematic_lock`。** 第一项检查（默认平板爪）还是钉住的，
   `--v-jaw --lift --no-lock` 那条才是全物理。默认值没换，因为几项旧判据建在旧数字上，
   换了会打断历史对比。
3. **163 N 在物理上算轻的。** 真机手拧 Φ100 三爪每爪 3~5 kN。现在卡在
   `CHUCK_FORCE_LIMIT = 150 N`（每爪名义 50 N），这是为了不让爪压穿卡盘设的上限，不是
   夹不动的上限。
4. **卡盘内孔是 24 片 box 拼的近似圆。** 挡住穿透够用，`chuck_body_N` 已经从
   1~4 kN 降到 0，扫描里的三爪力可以引用；但孔壁有棱，不是真圆环，别拿它做孔壁
   摩擦那种接触级研究。首屏 163 N 是送料末态量的，扫描 139~256 N 是悬臂装夹量的，
   工况不同，别对着减。
5. **力比 1.15 靠的是几何精度。** 三爪位移只差 0.09 mm，微米级的弧面形状差就是几十牛
   的力差。包角 42° 时这个差值被短弧片放大成 4.24 倍力不均，44° 才压回来。真机靠
   「爪装到卡盘上就地镗孔」消除，仿真里只能靠几何。
6. **Φ15 两组都还夹不了。** 新摆位下固定 Φ20 爪和按 Φ15 另镗的爪都在互顶上挂
   （48 对 / 42 对）。44° 是按 Φ20 定的，细料的角向缝不够；42° 以下定制爪能过，
   但主线三爪力比会放大到 4.24，所以全局没改。真要夹 Φ15 得单配一付小包角爪。
7. **摩擦系数偏乐观。** 卡爪 1.8 / 工件 1.2，磨光的车削件没这么高，还没按真实材料标定。
8. **`demo_09` 的 3/3 不检查姿态**，只验位置。
9. **没有 sim-to-real，没有自动避障。** 无真机、无标定、无参数迁移；路点是手给的，没有
   规划器。
10. **视觉、遥操作、模仿学习都还没开始。** 上面「未来」那节写的是计划，不是已完成。
