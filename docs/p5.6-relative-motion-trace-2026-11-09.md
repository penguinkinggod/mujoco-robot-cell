# P5.6 搬运相对位移逐步追踪

完成日期：2026-11-09

## 本卡回答的问题

P5.5 在三个相同 nominal 复跑中都测到 `8.151944 mm` 的搬运相对夹爪最大平移。本卡增加可选逐物理步记录，核查这个值何时形成、是否是一帧突变，以及当时有哪些工件接触。

结论：三次追踪都得到完全相同的时间序列和送料结果。最大相对位移在仿真 `7.912 s`、连续搬运轨迹阶段出现，工具坐标变化向量为 `[+3.305, +6.334, -3.926] mm`，模长 `8.152 mm`。位移在运动过程中逐步形成，并非单个采样帧突然跳出；随后进给修正阶段逐渐回落，到 `feed_complete` 时约为 `3.687 mm`。峰值帧有四组 V 爪碰撞几何与棒料接触。它确认的是当前 MuJoCo 模型里的可重复相对运动，不能单凭这些数值认定真实夹持是否合格，也不能把接触重叠直接认定为真实材料穿透。

## 记录方式

本卡只增加观察，不改变机器人目标、夹爪参数、接触参数、送料判据或仿真物理。新记录在 JSON schema v13 中，通过 `FEED_TRACE_RELATIVE_MOTION=1` 显式启用；普通运行仍不保存逐步历史。

三份数据都由代码基线 `e17a192c4cd2a16e6d9336c82b534983ac2b31a0` 加上本卡未提交的追踪改动生成；JSON 中因此记录 `git_worktree_dirty=true`。三份均由同一未变的代码工作树连续运行，追踪代码和报告随后一并本地提交。

- 记录区间：夹紧并完成抓取保持后开始，到 `feed_complete` 为止。
- 采样：MuJoCo 每个物理步一次，时间间隔 `0.002 s`。
- 每帧记录：仿真时间和动作标签、工件世界位姿、夹爪中心及末端 site 位姿、工件相对末端坐标系的位移向量/轴线变化、相对前一物理步的变化，以及每组棒料接触对的接触数、法向力合计和接触距离。
- 启用字段本身写入 `environment_overrides`，结果包含 `2034` 个逐步样本。

## 峰值时的接触

`7.912 s` 峰值帧中，棒料与固定/活动 V 爪的四组碰撞几何均有接触，每组有 2 个接触点。MuJoCo 记录的各组法向力合计约 `17.0–19.2 N`；各组最小 contact distance 约为 `-2.278` 至 `-2.604 mm`。该帧没有棒料与托架或机床的接触记录。

这里的力是当前接触求解器的仿真输出，不是实物夹持力标定；负 contact distance 表示模型碰撞几何重叠，不等于经测量确认的真实材料变形。P5.3 记录的全搬运阶段最深接触仍约为 `-2.991 mm`，并不恰好发生在 `8.152 mm` 位移峰值；因此现有证据不能简单地说“最大穿透造成了最大位移”。

## 判断与边界

- P5.5 已确认工具坐标变换的实现不会把机械臂整体刚体运动算成相对运动；P5.6 又在三次完整时间记录中精确复现峰值和时间，故这不是单纯坐标参照错误或随机单帧噪声。
- 在这三次固定 nominal 里，相对位移在连续搬运轨迹阶段上升至峰值，在后续进给修正阶段下降；它不是抓取起点到最终结果之间的简单单调滑移。
- 现有 `FEED_METRIC PASS` 仍是原来的端点/交接判据，不含搬运相对位移门槛。三次相同只证明仿真重复性，不证明工程容许性、实物精度或广泛工况鲁棒性。
- 当前接触模型没有实物标定。本卡不据此修改 V 爪、轨迹或接触参数。

## 复现

在仓库根目录执行：

```powershell
$env:MUJOCO_GL = "glfw"
$env:PYTHONUTF8 = "1"
$env:FEED_TRACE_RELATIVE_MOTION = "1"
$CASE_ID = "p56-nominal-relative-trace-1"
$env:FEED_CASE_ID = $CASE_ID
$env:FEED_RESULT_JSON = "_build\$CASE_ID.json"
& .\.venv\Scripts\python.exe -X utf8 .\src\diag_feed_chuck.py `
  --v-jaw --lift --no-lock `
  --initial-dy-mm 0 --initial-dz-mm 0 --initial-yaw-deg 0 `
  --initial-settle-steps 600 --control-mode M1 `
  *> ("_build\{0}.log" -f $CASE_ID)
```

复跑时将 case ID 分别换成 `p56-nominal-relative-trace-2` 和 `p56-nominal-relative-trace-3`。原始 JSON 与日志保存在被 Git 忽略的 `_build` 目录；分析摘要和复现方式纳入本报告。
